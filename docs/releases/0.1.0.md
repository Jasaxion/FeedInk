# FeedInk 0.1.0 — 基础阅读器

## 本版本内容

- 多用户账号、独立演示空间、订阅发现、文件夹、标签和稍后阅读。
- RSS、Atom、JSON Feed，全文提取、正文和图片持久存档。
- 搜索、排序、阅读状态与进度，桌面/手机/平板布局及墨水屏主题。
- 可安装 PWA、正文和图像离线缓存、离线状态同步、更新及账号隔离。
- OPML、可移植存档和 EPUB；操作员配置的邮件发送。
- Docker Compose、非 root 运行、管理员安全初始化、数据库迁移及成对备份恢复。

本版本尚不包含文章内文字/手写批注、相关笔记导出和 MCP AI 接口；这些属于接下来的开发阶段。

## 部署

请按 [部署说明](../deployment.md) 配置私有 `.env`、生成独立密钥、启动 PostgreSQL、通过操作员 CLI 初始化管理员，再启动应用。源码包含锁定依赖及 Dockerfile；不要将部署配置、密码、笔记或数据卷提交到仓库。

升级或迁移前阅读 [备份与恢复](../backup.md)。公开验证记录只保留经过审阅的汇总，不发布原始会话和私有诊断资料。
