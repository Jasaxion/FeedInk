# 产品范围与验收约定

FeedInk 是多用户自托管的 RSS 阅读器，交付 Web 与可安装 PWA，适配桌面、平板、手机和电子墨水屏浏览器。不提供原生平台安装包。技术栈为 React/TypeScript、Node.js 与 PostgreSQL；数据库和文件存储独立持久化，使用 Docker Compose 部署。

## 核心能力

| 领域 | 验收行为 |
|---|---|
| 账号 | 注册、登录、退出、密码变更；隔离的原创演示空间；操作员安全初始化管理员；各账号的订阅、文章、标签、图片及阅读状态隔离 |
| 订阅 | RSS、Atom、JSON Feed；从网页发现订阅地址；主题与关键词发现；自动轮询、条件请求、手动刷新和清晰错误状态；支持完整 RSSHub 路由 |
| 整理 | 文件夹与标签管理；订阅改名、移动、置顶和静音；源与文件夹阅读偏好；未读计数；带分组的 OPML 导入导出 |
| 列表 | 三栏、单行、杂志与网格；分页、未读筛选、排序、时间筛选、中文及英文搜索；滚动标读、批量标读和保留阅读位置 |
| 阅读 | RSS 正文、归档全文、受限原网页视图及外部打开；上下篇、进度、稍后阅读、标签、图片预览与下载；安全呈现代码、链接和媒体 |
| 持久化 | 正文、全文与图片保留来源、捕获时间和完整性摘要；订阅取消或源站失效不删除已有存档；可移植 ZIP 导出恢复；数据库与文件卷成对备份 |
| 图像 | 处理相对地址、懒加载属性和响应式图像；受限的服务端抓取、重试及失败降级；不会作为任意 URL 的开放代理；不绕过登录、付费墙或访问控制 |
| 设置 | 明暗、跟随系统、护眼与墨水屏主题；字体、字号、行高和正文宽度；桌面与手机列表偏好；懒加载、点击翻页、代码换行和受限自定义样式 |
| 快捷操作 | 原生键盘焦点与按钮激活不受损；列表/阅读快捷键、触摸返回、分页和上下文操作；输入表单时不抢占按键 |
| 电子书与媒体 | 含本地图像的 EPUB；SMTP 发送与定时选择；不确定发送结果需显式核对；浏览器播客与语音朗读控件，在能力不支持时明确提示 |
| PWA | 自有图标、manifest、service worker 与安装指引；应用壳和已缓存正文/图像可离线读取；待同步状态持久化，恢复后以版本前提同步；更新提示；退出与换账号隔离缓存 |
| 响应式与墨水屏 | 多种视口下无内容或控件遮挡；高对比、无动画的墨水屏模式；足够的触摸目标和可访问焦点；尊重减少动态效果的系统偏好 |
| 部署 | 锁定依赖、生产镜像、非 root 运行、健康检查、数据库迁移、独立持久卷、HTTPS 指引、安全备份恢复、升级回滚和版本记录 |

## 验证原则

- 用受控、原创的 HTTP、图像、SMTP 和数据库夹具验证行为；不使用第三方账号、凭据或私人文章作为测试数据。
- 分别验证服务端存档、浏览器本地缓存、源站不可达和设备离线，不将文件存在或页面截图当作全部功能通过。
- 所有并发、权限、解析、存储异常与恢复修复都需要回归测试。具体边界和资源上限应在界面或文档中明确说明。
- 测试产物不得包含真实用户数据、访问凭据、机器路径或第三方服务的内部信息。公开文档仅描述 FeedInk 自身能力。
- 任务进度由项目任务系统管理；本文件是产品约定，不是完成状态清单。
